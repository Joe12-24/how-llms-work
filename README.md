## 内容（v2）
- 第 0 幕：30 秒直觉 — 大模型就是超级接龙机，只猜下一个词
- 地基实验室 · 手写数字：按 Tariq Rashid《Python神经网络编程》复刻 MNIST 小实验 — 可手绘识别演示（原型权重模拟）、向后查询权重热力图、四组原书实测参数实验（学习率/世代/隐藏节点/旋转增强）、概念小灶与 2016→现在新老对照表
- 第一幕 · 训练：语料 → Token → 猜词 → Loss → 梯度 → 更新参数；学习率滑杆 + Loss 曲线
- 第二幕 · 推理：分词 → Embedding → Attention → 概率分布 → 温度采样 → 自回归逐词生成；含「问天气为什么不接着编」三段对比
- 第三幕 · Agent：while 循环（调模型 → 调工具 → 结果写回上下文），上下文增长、三大翻车点、RAG / Function Calling 祛魅
- 右上角「进阶模式」开关：交叉熵 Loss 深讲、词向量语义地图、Q/K/V、「还是只预测下一个 token 吗」澄清
